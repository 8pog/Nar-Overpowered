🚀 Nar Overpowered Hub
An all-in-one, highly optimized Windows system utility and optimization hub designed and developed by Developer Nar. Built natively with Python and CustomTkinter, it offers a sleek, dark-themed UI with full English and Arabic localization.

✨ Features / المميزات الأساسية
🌍 Dual-Language Support: Seamlessly switch between English and Arabic with a single click.

⚡ All-in-One Dashboard: Consolidates multiple critical Windows tweaks into one clean interface.

🛠️ Included Modules:

Explorer Configuration: Customize File Explorer layout, navigation pane items, compact mode, and context menus.

System Tweaker: Optimize power plans, disable unnecessary telemetry/background apps, and perform quick system cleanups.

Bloatware Remover: Safely scan and remove pre-installed Windows bloatware and AI components.

Windows AI Manager: Fine-tune, enable, or disable Windows AI features (like Copilot, Recall, and data harvesting).

🔒 Safe & Administrative: Automatically requests administrator privileges to apply system-level changes securely.
